根目录作为 Maven 聚合项目（packaging=pom），在 pom.xml 中声明 <modules>frontend</modules> 与 <backend></modules>，由 backend 下的 Spring Boot 应用 io.metersphere.Application 作为唯一运行时入口；Dockerfile 将 backend/app/target/dependency 中的可执行 jar 与 frontend/public 静态资源合并到 /app/static，通过 JAVA_MAIN_CLASS=io.metersphere.Application 启动，从而把前端 SPA 与后端单体服务打包进同一镜像。Jenkinsfile 是统一的 CI 流水线：先按分支名推导 REVISION，再根据 BUILD_SDK 参数选择仅部署 SDK 或执行 `./mvnw clean install` 并解压 jar 到 backend/app/target/dependency 后构建多架构镜像。根级 lombok.config、.gitignore、LICENSE、OWNERS 等文件对两个子模块共享生效。
