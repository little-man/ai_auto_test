Node >= 18；开发启动 `npm run dev`（加载 `config/vite.config.dev.ts`），生产构建 `npm run build`（先执行 `vue-tsc --noEmit` 类型检查再 `vite build --config ./config/vite.config.prod.ts`）；本地预览用 `npm run preview`；提交前由 husky + lint-staged 自动运行 prettier/eslint/stylelint；可通过 `npm run report` 启用 rollup-plugin-visualizer 分析打包体积。
