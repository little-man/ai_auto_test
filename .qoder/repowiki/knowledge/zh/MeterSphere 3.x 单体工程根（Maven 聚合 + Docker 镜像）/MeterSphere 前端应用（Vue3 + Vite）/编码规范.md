- API 接口按业务域拆分到 `src/api/modules/<domain>/`，URL 常量镜像放置于 `src/api/requrls/<domain>/`，保持调用方与路径定义解耦。
- 组件目录分为 `components/pure/`（无业务语义的基础组件，如 ms-table、ms-dialog）与 `components/business/`（跨页面复用的业务组件，如 ms-ai-drawer、ms-associate-case）。
- 视图与模型按领域划分：`src/views/<domain>/` 对应 `src/models/<domain>/`，每个领域内再按子功能（如 api-test/debug、scenario、report）进一步拆分。
- 可复用逻辑统一抽取为 `src/hooks/useXxx.ts` 的组合式函数（如 useUser、usePermission、useTableStore、useWebsocket），供多个视图共享。
- 多语言文案放在 `locale/<lang>/` 下按 common/settings/sys 分文件，组件级文案则放在组件目录内的 `locale/` 子目录中。
- Vite 配置按环境拆分：`vite.config.base.ts` 聚合公共插件与别名，`vite.config.dev.ts` / `vite.config.prod.ts` 分别扩展开发/生产特性，脚本通过 `--config` 参数切换。
