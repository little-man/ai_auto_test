模块采用典型的 Vue3 SPA 分层结构：
- 构建层：`config/vite.config.base.ts` 作为基础配置，通过 `vite.config.dev.ts` / `vite.config.prod.ts` 按环境拆分；使用 `@arco-design/web-vue` 主题包 `@arco-themes/vue-metersphere-v3`，并集成 SVG 图标、自动导入、Less 变量注入等插件。
- 入口层：`src/main.ts` 装配 Pinia、i18n、Router、Arco 组件库、自定义指令、DOMPurify、LocalForage 后挂载 App。
- 路由层：`src/router/index.ts` 使用 `createWebHashHistory`，集中注册基础路由并通过 `guard/` 下的权限守卫拦截；业务路由按领域拆在 `router/routes/modules/`。
- 状态层：`src/store/` 基于 Pinia，按 app/global/user/case/testPlan/setting 等模块拆分，并通过 `plugins.ts` 注入 debounce 与 `pinia-plugin-persistedstate` 持久化。
- API 层：`src/api/` 将 HTTP 客户端封装（`api/http/Axios.ts`）与接口定义分离为 `modules/<domain>/` 和 `requrls/<domain>/` 两套镜像目录，实现请求函数与 URL 常量解耦。
- 数据模型层：`src/models/` 以 domain 维度组织 TS 类型与 mock 数据，与 views 解耦。
- UI 层：`src/components/pure/` 存放无业务语义的原子组件（ms-table、ms-dialog、ms-form-create 等），`src/components/business/` 存放跨页面复用的业务组件（ms-ai-drawer、ms-associate-case、ms-minders 等）；`src/views/` 按功能域（api-test、case-management、bug-management、test-plan、project-management、setting、workbench 等）组织页面级视图。
- 支撑层：`src/hooks/` 暴露组合式逻辑（useUser、usePermission、useTableStore、useWebsocket 等），`src/directive/` 提供 permission/outerClick/license 等全局指令，`src/locale/` 基于 vue-i18n 维护 zh-CN/en-US 双语言。
- 部署层：`Dockerfile` 基于 nginx:1.24.0 托管 `dist/` 静态资源，配合根目录 `nginx.conf` 反向代理后端。
