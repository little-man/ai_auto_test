采用三层 Maven 聚合结构：
- `app`：Spring Boot 可执行入口 `Application.java`，排除 Quartz/LDAP/Neo4j 自动装配，加载 `commons.properties` 与 `/opt/metersphere/conf/metersphere.properties`，并启用 Minio/Jmeter 配置属性。
- `framework`：共享基础层，再细分为 `domain`（MyBatis 实体 + Mapper + Flyway 迁移脚本 `migration/{version}/ddl|dml`）、`sdk`（常量、DTO、工具类、i18n、Totp 等公共库）、`provider`（跨业务关联的 Provider 抽象）、`plugin`（定义 `plugin-api-sdk` / `plugin-platform-sdk` / `plugin-sdk` 三套 SPI，供外部插件实现）、`ai-engine`（基于 Spring AI 的 ChatClient 多厂商适配 DeepSeek/OpenAI/ZhiPu）。依赖方向单向：services → framework。
- `services`：按业务域拆分的独立 Spring Boot 子模块（`api-test`、`bug-management`、`case-management`、`project-management`、`system-setting`、`test-plan`、`dashboard`），每个子模块遵循 controller→service→mapper 分层，并通过各自的 `*GeneratorConfig.xml` 使用 MyBatis Generator 生成代码，`resources/permission.json` 声明权限点。

依赖方向严格自上而下：`app` 依赖 `services`，`services` 依赖 `framework`，`framework` 内部各子模块相互解耦。
